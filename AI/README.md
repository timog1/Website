# AI Instructions

Quick-reference files for AI assistants working on this project. Send the relevant files when asking for help.

## Structure

| File | When to Use |
|------|-------------|
| `project.md` | Always — gives full context about the project |
| `architecture.md` | When working on components, routing, or structure |
| `coding-standards.md` | When writing or refactoring code |
| `skills/angular.md` | Angular-specific questions (components, signals, DI) |
| `skills/tailwind.md` | Styling questions |
| `skills/ssr-hydration.md` | SSR, hydration, or server rendering issues |

## How to Use

- **General help**: Send `project.md` + `coding-standards.md`
- **New component**: Send `project.md` + `architecture.md` + `skills/angular.md`
- **Styling**: Send `skills/tailwind.md`
- **SSR issues**: Send `skills/ssr-hydration.md`
